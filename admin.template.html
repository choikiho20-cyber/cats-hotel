첫 화면

홈페이지를 열면 가장 먼저 보이는 큰 사진과 제목입니다.

전화번호 · 시간

전화 버튼·문자 버튼·예약 버튼·검색 정보가 전부 이 번호로 바뀝니다.

사진첩

홈페이지 사진 창의 분류별 사진입니다. ◀ ▶로 순서를 바꾸고 ✕로 뺍니다. 맨 앞 사진이 대표로 먼저 보입니다. 주차장은 앞 5장이 주차 구간에 크게 나옵니다.

객실

요금을 비우면 "요금 문의"로 나옵니다. 설명은 한 줄에 하나씩 적으세요.

자주 묻는 질문

질문은 물음표로 끝내 주세요. 답에 {phone} {checkin} {checkout} {daesil}라고 쓰면 연락처·시간 값이 자동으로 들어갑니다.

이용 안내

왼쪽 제목(숙박·대실·주차…)과 오른쪽 설명입니다.

유튜브 영상

유튜브 영상 주소를 넣으면 홈페이지 사진첩 앞에 "영상으로 보기" 칸이 생깁니다. 비우면 칸이 사라집니다.

평점

예약 앱에 보이는 숫자를 그대로 옮겨 적으세요. 기준 날짜도 같이 바꿔 주세요.

채널 주소

주소를 넣는 순간 홈페이지 버튼·맨 아래 링크에 저절로 나옵니다. 네이버 예약 주소를 넣으면 객실마다 있는 [네이버 예약 준비 중]이 진짜 예약 버튼으로 바뀝니다.

비밀번호

사장님·직원이 들어올 때 쓰는 비밀번호입니다. 직원이 그만두면 바꿔 주세요.

변경 기록
사용법 — 처음이시면 눌러 보세요

1. 이 화면을 휴대폰 첫 화면에 두기

  • 아이폰: 아래 가운데 [공유] → [홈 화면에 추가]
  • 갤럭시: 오른쪽 위 [⋮] → [홈 화면에 추가]
  • 비밀번호는 이 기기에서 한 번만 넣으면 됩니다.

2. 위쪽 메뉴

  • 소식·블로그: 새 글 쓰기, 쓴 글 고치기·내리기
  • 첫 화면·공지: 큰 사진·제목·한 줄 소개, 공지 한 줄 켜고 끄기
  • 연락처·시간: 전화번호, 입실·퇴실·대실 시간
  • 사진첩·객실: 사진 추가·빼기·순서, 객실 요금·설명
  • 고친 뒤 아래 [저장]을 누르면 1~2분 뒤 홈페이지에 반영됩니다.

3. 새 글 쓰기

  1. [소식·블로그] → [+ 새 글 쓰기]
  2. 제목: 지역 + 무엇 (예: 제천종합운동장 근처 숙소, 단체 주차는 몇 대?)
  3. 요약: 이 글의 답을 한두 문장으로. 검색 결과에 그대로 보입니다.
  4. 태그: 쉼표로 (예: 제천숙소, 제천출장숙소)
  5. 본문: [소제목]은 질문으로, 바로 아래 첫 문장에 답을 적으세요.
  6. [저장] → 1~2분 뒤 홈페이지 소식에 올라갑니다.

4. 쓴 글 고치기

  • 글 목록에서 글을 누르거나
  • 홈페이지 글을 보다가 오른쪽 아래 「이 글 수정」을 누르세요(이 기기에서만 보입니다).

5. 사진

  • 글에 넣기: 넣을 자리를 한 번 누르고 → [사진 넣기]. 여러 장 한 번에 됩니다. 크기는 자동으로 줄어듭니다.
  • 글에서 빼기: 사진을 눌러 빨간 테두리가 생기면 → [고른 사진 빼기]
  • 사진첩·객실: [+ 사진 추가], 순서는 ◀ ▶, 빼기는 ✕

6. 검색에 잘 걸리는 요령

  • 숫자로 쓰기 — 가격, 시간, 인원, 거리
  • 실제 사진 쓰기, 지어낸 후기 쓰지 않기
  • 글 하나에 주제 하나

7. 실수했을 때 · 안 될 때

  • 방금 한 것 취소: [되돌리기]. 저장 전이면 화면을 새로고침하면 바뀐 것이 버려집니다.
  • 「저장 실패」: 인터넷을 확인하고 [저장]을 다시 누르세요.
  • 저장했는데 안 바뀜: 1~2분 기다린 뒤 홈페이지를 새로고침(휴대폰은 아래로 당기기)
  • 비밀번호가 안 맞음: 관리하는 분께 새 비밀번호를 받으세요.

8. 비밀번호 관리 (관리하는 분)

  • 비밀번호는 카톡 단체방에 올리지 마세요.
  • 직원이 그만두면 [그 밖] → [비밀번호 정하기·바꾸기]로 바꾸세요. 그러면 모든 사람이 새 비밀번호를 넣어야 합니다.
  • 바꿀 때는 이 홈페이지 전용 GitHub 토큰이 한 번 필요합니다. 모르시면 만든 곳에 문의하세요.
